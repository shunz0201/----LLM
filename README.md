# インベーダーゲーム

ブラウザで遊べるインベーダーゲームです。`index.html` をブラウザで開くだけで動きます（外部ライブラリ不要）。

## 操作
| キー | 動作 |
|---|---|
| ← → / A D | 移動 |
| Space / ↑ | 発射 |
| P | 一時停止 |
| Enter | スタート / リトライ |

スマホではタッチボタン（◀ ● ▶）で操作できます。

## 特徴
- 3種類のインベーダー（10 / 20 / 30点）と謎のUFO（50〜300点）
- 壊れるシールド、残機3、ウェーブ制（進むほど速く・低く・弾が多く）
- 残りが少ないほどインベーダーが加速
- WebAudio による効果音、ハイスコア保存（localStorage）
